Turie — Adventure Travel & Tourism Website

A fully responsive adventure travel and tourism website built from scratch using HTML5, CSS3, and JavaScript. Designed with an earthy Jungle & Earth colour palette, the site showcases destinations, trips, and travel services with smooth animations and interactive components.

 Live Preview
> Open `index.html` in your browser to view the project locally.

 Project Overview

WildRoute is a front-end travel website designed for an adventure tourism brand. It features a modern, visually rich layout with multiple sections covering everything from destination discovery to trip booking — built entirely with front-end technologies.


 Technologies Used
 Core
- HTML5
- CSS3
- JavaScript (Vanilla)
- jQuery

Third-Party Libraries & Plugins
| Library | Purpose |
| bxSlider | Hero image slider and logo carousel |
| Lightbox2 | Photo gallery zoom/lightbox effect |
| Animate.css | Pre-built CSS animations |
| WOW.js | Scroll-triggered reveal animations |
| Font Awesome 6 | Icons throughout the site |
| Google Fonts | Fraunces (headings) + DM Sans (body) |

 Design System
  Colour Palette — Jungle & Earth
| Name | Hex | Usage |

Typography
- Headings — Fraunces (Google Fonts) — serif, organic feel
- Body & UI — DM Sans (Google Fonts) — clean, readable

 Key Features

- Fully responsive layout using CSS Flexbox and Grid
- Full-width hero banner with auto-sliding images and custom prev/next arrows
- Trip search form with:
  - Destination dropdown grouped by region (India + International)
  - Travel and return date pickers with min-date validation
- Rain animation effect in About Us section
- Scroll-reveal animations using WOW.js + Animate.css
- Photo gallery with Lightbox2 zoom on click
- Destination cards with pricing, ratings, duration, and group size
- Custom CSS animations — hover effects, transitions, bounce effects

How to Run

1. Clone or download the repository
2. Open the project folder
3. Open `index.html` in any modern browser
4. No server or installation required — pure front-end project

What I Learned

- CSS positioning, Flexbox, and Grid for complex layouts
- Integrating and customising third-party jQuery plugins
- Working with CSS animations and scroll-triggered effects
- Designing a consistent colour system and typography scale
- DOM manipulation using vanilla JavaScript and jQuery

 Note

This is a front-end only project. No backend, database, or server-side functionality is implemented. Form submissions and booking actions are UI only and do not process real data.
